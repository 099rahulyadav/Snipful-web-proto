# Snipful marketing site

Static three-page product website for Snipful.

## Pages

- `index.html` — product homepage
- `pricing.html` — Free and Pro plan comparison
- `contact.html` — contact experience with disconnected submission routing

Open `index.html` directly or serve this directory with any static file server.

Authentication links, browser-extension destinations, documentation links, legal links, and contact submission routing are intentionally left unconnected.
